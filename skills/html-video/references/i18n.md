# 按需多语言扩展参考（Opt-In i18n）

仅当用户明确要求多语言版本时启用本指南。分镜源码（`js/scenes.js`）保持纯原生单语种写法，所有外语覆写均收敛在 `locales/<lang>.js`。

## 1. 显式开启白名单

在 `video.config.js` 中声明 `lang`（母语）与 `locales`（开放语种白名单）：

```js
V.config = {
  lang: 'zh-CN',
  locales: ['zh-CN', 'en'], // 未配置 locales 时自动忽略外部 URL ?lang=，防止宿主参数误伤原声
};
```

- 声明 2 个及以上语种时，播放器声音菜单自动渲染语种切换项。
- 请求未列入 `locales` 的语种，或对应语种脚本与配音均不存在时，自动回退母语。

## 2. 外挂语种包（原文直映，免改分镜）

新建 `videos/<id>/locales/en.js`，无需在 `scenes.js` 埋 `key`：

```js
V.locale('en', {
  label: 'English',
  title: 'Interactive HTML Video',
  tts: {
    voice: 'en-US-EmmaMultilingualNeural',
    speakers: {
      host: { label: 'Ling', voice: 'en-US-AvaMultilingualNeural' },
    },
  },
  texts: {
    '全局角标': 'Global Badge',
    '继续演示？': 'Continue demo?',
    '继续': 'Continue',
  },
  scenes: {
    intro: {
      title: 'Core Mechanism',
      texts: {
        'HTML 原型先行': 'HTML Prototype First',
      },
      anchors: { 对齐: 'align' },
      lines: ['Align interaction logic in HTML first, then archive structured docs.'],
    },
  },
});
```

- **画布与驻点文案（`texts`）**：切换到非母语时，引擎自动遍历当前幕文本节点，将匹配的母语原文替换为译文并缓存原值；母语态跳过扫描（零开销）。仅当同一幕出现“同词不同译”时，才按需使用 `x.t('disambigKey', '原文')` 或 `data-i18n="disambigKey"`。
- **词锚映射（`anchors`）**：将分镜内 `x.at(0, '对齐')` 的母语关键词映射到目标语种重音词 `'align'`。
- **播放器界面文案（`uiStrings`）**：内置 `zh-CN`、`zh-TW`、`en` 三套控制栏与提示词，其余语种默认回退英文，可在 `V.locale` 内传 `uiStrings` 覆盖。

## 3. 多语种构建与运行时切换

| 场景 | 命令或接口 |
| :--- | :--- |
| 合成外语配音与字幕 | `npx html-video build <id> --lang en`（独立产物 `soundtrack.en.m4a`、`bgm.en.m4a`、`timings.en.js` 与 `.en.vtt/.srt`） |
| 校验外语同步 | `npx html-video verify <id> --lang en` |
| 导出外语 MP4 | `npx html-video render <id> out.en.mp4 --lang en` |
| 网页热切语种 | URL 参数 `?lang=en`、声音菜单语种项，或编程调用 `await V.setLang('en')`（按当前幕与句内相对进度无缝对齐） |
